# Создание актов и восстановление ввода

Новые АОСР получают статус `READY` («Создан»). Переключатель «Черновик»
на форме создания и редактирования задаёт `DRAFT`; выключение переводит
черновик в `READY`. Статус `FINAL` по-прежнему связан с отдельной фиксацией
подписантов и сохраняется при обычном редактировании финального акта.
Миграция `0024_existing_acts_ready` однократно переводит все существующие
акты со статусом `DRAFT` в `READY`, сохраняя `FINAL`. Новые явно выбранные
черновики после применения миграции остаются черновиками. Откат миграции
не возвращает прежние статусы, чтобы не переклассифицировать новые акты.
В списке черновики выделены светло-жёлтой строкой с подсказкой при наведении.
Копирование акта сохраняет
прежнее поведение: копия создаётся черновиком для проверки.

При развёртывании применить миграции до `acts_app.0024_existing_acts_ready` и обновить
статические файлы штатным способом проекта.

Страница создания сохраняет незавершённый ввод в `localStorage`, отдельно
для каждого пользователя. Сохраняются поля, выбранные проекты и согласования,
добавленные и удалённые строки. При возвращении предлагаются восстановление
или удаление копии. Копия не является актом в базе данных. Файлы повторно
выбираются пользователем; браузер не позволяет восстановить выбор файла.
Копия удаляется после перехода к успешно созданному акту с совпадающим
токеном отправки. Ошибка валидации или неудачная отправка её не удаляют.
При недоступном хранилище показывается сообщение, сохранение акта продолжает
работать. Другая вкладка не перезаписывает копию с отличающимся токеном.

Проверки (из корня проекта, с установленными зависимостями):

```text
python manage.py test acts_app.test_creation acts_app.tests acts_app.test_signatories --settings=settings.acts_test_settings --noinput
python scripts/render_act_form_test.py <временный-файл.html>
node scripts/test_act_form.cjs <временный-файл.html>
```

Браузерная проверка требует Node.js 20+, Playwright и Microsoft Edge.
Она использует изолированный контекст и перехватывает все сетевые запросы,
проверяя реальный шаблон формы без доступа к рабочей базе.
